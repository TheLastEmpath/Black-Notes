## 0.1.0

First prototype of Black Notes, a project board for a Discord community.

- Projects are listed under the person who started them, with a progress bar and an in-process or deployed label.
- A Discord post only becomes a project when its author marks it with the verify emoji. Nobody else can do it for them.
- A Candidates page shows posts that look like builds and posts that sound like ideas.
- Each project has a room: build notes, suggestions, and a live chat.
- Only the project owner can change progress, add people, or accept suggestions.
- This version runs on a simulated Discord. It does not connect to the real server yet.
